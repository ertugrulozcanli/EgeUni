# FastMCP Ödevi
Bu proje, FastMCP kütüphanesi kullanılarak oluşturulmuş basit bir MCP sunucusudur. 

## Özellikler
- **Tool:** Şehir ismine göre hava durumu tahmini yapar.
- **Resource:** Proje hakkında bilgi veren bir kaynak barındırır. 
Kodun calismasi icin terminalde dosyanın olduğu klasör veya yolda olmanız gerek.
